# 🚀 HƯỚNG DẪN QUICK START

Hệ thống rút gọn phục vụ Demo môn **Lập Trình Mạng**.

## Yêu cầu
- Đã cài đặt **Node.js** (v16 trở lên).

## Bước 1: Chạy Server (Backend)

1. Mở terminal tại thư mục `backend`:
   ```bash
   cd d:\iphone-main\backend
   ```
2. Cài đặt thư viện (nếu chưa):
   ```bash
   npm install
   ```
3. Khởi chạy:
   ```bash
   npm start
   ```
   ✅ *Thấy dòng*: `Server đang chạy tại port 5000` là OK.

## Bước 2: Chạy Client (Frontend)

1. Mở terminal **MỚI** tại thư mục `iphone-main`:
   ```bash
   cd d:\iphone-main\iphone-main
   ```
2. Cài đặt thư viện (nếu chưa):
   ```bash
   npm install
   ```
3. Khởi chạy:
   ```bash
   npm run dev
   ```
   ✅ *Thấy dòng*: `Local: http://localhost:5173/` là OK.

## Bước 3: Xem kết quả

Mở trình duyệt: [http://localhost:5173](http://localhost:5173)

Nếu bạn thấy danh sách sản phẩm (có chữ **Server Mock**) -> 2 máy đã kết nối thành công! 🎉
